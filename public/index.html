⚡ Automatic Reference Matching

Domino's Order Engine uses automated cryptographic reference tags. You do not need to manually copy or type in bank UTR transaction numbers!

  1. Unique Transaction Reference (TR): When you request a deposit, the system creates a unique reference (e.g. DEP-XXXXXX) with an active 5-minute validity window.
  2. Prefilled in UPI Intent & QR: The QR code and ⚡ Pay via UPI App button embed this reference code into the payment memo (tr=DEP-... and tn=Domino's Order Engine Deposit DEP-...).
  3. Instant Desk Auto-Matching: Once payment is sent from your UPI app, our system and admin match your payment directly by reference code.
  4. 5-Minute Security Expiry: Each QR remains valid for 5 minutes. If your payment was completed right as the QR expired, simply click Contact Support with your reference code for instant manual balance credit.
